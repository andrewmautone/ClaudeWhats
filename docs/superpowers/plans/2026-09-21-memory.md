# ClaudeWhats Memory (OptMem port) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `claudewhats memory <wake|note|nap|recall|zoom|forget>` — a Go port of OptMem's `memo`, byte-compatible with its on-disk format, plus a `## memória` block printed by `read`/`summary --chat` before the messages.

**Architecture:** New package `internal/memory` holding the store (fixed-width LOG/TREE records, seek-based access, file lock), the cover/pending algorithm, and the command bodies returning strings; `internal/cli/memory.go` wires cobra; `read`/`summary` call `memory.Recall`. Reference implementation to port: `C:\Users\Andrew\.optmem\memo` (Python, 859 lines) — port function by function, keeping names.

**Tech Stack:** Go 1.26, stdlib only (`os`, `regexp`, `syscall` for locks), existing cobra CLI.

**Spec:** `docs/superpowers/specs/2026-09-21-claudewhats-design.md` — section "Memória OptMem".

## Global Constraints

- Byte-compatible with OptMem: `LOG.txt` records are exactly `LOG_REC=320` bytes (`#<i> <YYYY-MM-DD> <text>` UTF-8, padded with spaces, last byte `\n`); `TREE/<size>` records are `TREE_REC=288` bytes; entry text ≤ `ENTRY_CHARS=280` bytes; `WAKE_LINES=96`; `RAW_MAX=16`; `PART_CHARS=20000`, `PART_LINES=500`. Read the exact padding/parse rules from the Python (`pad`, `parse`, `records`, `repair`) and reproduce them; verify with fixtures produced by the Python tool.
- Memory dir: `<config.Home>/memory` (i.e. `~/.claudewhats/memory`), override with env `CLAUDEWHATS_MEMORY_DIR`. Files: `LOG.txt`, `TREE/<size>`, `config` (same knob file format; only read, `memory config` not implemented in v1).
- Performance: no command loads the whole LOG except `recall` (streamed in 320-byte records, regex compiled once). `wake` seeks only the records of its cover. `note` = one append + `stat`-based nap prompt. Benchmarks: `wake`, `note`, `recall` on a 10k-entry log each < 20 ms (`testing.B`, assert in a regular test with a generous 100 ms ceiling to avoid CI flakes).
- Write lock: `LOCK` file in the memory dir; `flock` on unix, `LockFileEx` on windows (build-tagged files).
- Output text (prompts, headers, "Not awake yet", "You are awake.", "Saved as #N.", nap prompts, "Nothing left to compress.", "Too long: N bytes, limit 280...") must match the Python's strings so the Claude skill behaves identically — except the tool name, which is `claudewhats memory`.
- Commit messages in English ending with `Co-Authored-By: Claude Opus 5 (1M context) <noreply@anthropic.com>`.
